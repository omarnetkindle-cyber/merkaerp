# Tasas moratorias historicas: alcance pendiente

La formula local usa tasa diaria equivalente y fue probada. La Superintendencia Financiera publica el historico oficial de Interes Bancario Corriente/tasa de usura, pero el proyecto no conserva una tabla de vigencias ni un proceso de importacion verificable. No se sembraron valores manuales o parciales para evitar que una serie incompleta se use al liquidar obligaciones antiguas.

Diseno pendiente: tabla con fecha inicial/final, modalidad, IBC EA, TIM EA, resolucion/fuente oficial y fecha de carga; el calculo debe partir los dias de mora por vigencia.
